# Rice Disease Detection using Deep Learning

This project detects rice leaf diseases using AI and Deep Learning techniques.

## Features
- Image classification
- Disease prediction
- CNN / MobileNetV2 model
- Trained on rice leaf dataset

## Technologies Used
- Python
- TensorFlow
- Keras
- OpenCV
- Google Colab

## Results
Achieved high accuracy in detecting multiple rice diseases.
